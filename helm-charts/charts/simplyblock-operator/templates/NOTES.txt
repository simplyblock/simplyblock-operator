The simplyblock operator is being deployed to your cluster.

The following components are being installed or updated:

- simplyblock CSI Driver
{{- end }}
- simplyblock Operator and its CRDs
{{- if eq .Values.deployment.profile "standalone" }}
- simplyblock Control Plane, installed by the operator

{{ if eq .Values.deployment.profile "standalone" -}}
This deployment hosts its own control plane. The chart wrote the ControlPlane
object and the operator installs FoundationDB, the object store, and the
management API from it, in that order. The database has to reach quorum before
the management API starts, so the first install takes a few minutes.

Watch it settle:

  kubectl --namespace={{ .Release.Namespace }} get controlplane simplyblock -w

Wait for it to become Available:

  kubectl --namespace={{ .Release.Namespace }} wait controlplane simplyblock \
    --for=jsonpath='{.status.phase}'=Available --timeout=600s
{{- else if eq .Values.deployment.profile "empty" }}
This deployment installs the operator alone. Nothing is running for it to act
on until you write the objects it reconciles, in this order:

  1. A ControlPlane named simplyblock, with spec.source.local to host the control
     plane here or spec.source.managed to point at one elsewhere.
  2. A SimplyblockDriver, which is what the operator builds the CSI driver from.
     Volumes cannot be provisioned until it exists.

Check that the operator is running:

  kubectl --namespace={{ .Release.Namespace }} rollout status deployment/simplyblock-operator
{{- else }}
This deployment is managed by a control plane at
{{ .Values.controlplane.managed.endpoint }}. Nothing is installed here for it:
the operator resolves that endpoint, probes it, and reports.

Check that it is reachable:

  kubectl --namespace={{ .Release.Namespace }} get controlplane simplyblock
{{- end }}

status.phase is Available once the control plane answers. Degraded means it
answers while something behind it is short, and status.components names which.

Once it is Available, you can start creating simplyblock resources. Refer to the
documentation to get started:

  https://docs.simplyblock.io/latest/kubernetes/installation/k8s-storage-plane/

To follow the pods, please run:

  kubectl --namespace={{ .Release.Namespace }} get pods --watch

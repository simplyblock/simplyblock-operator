## 2. Not Covered

- **End to end against a live control plane:** the plan, the forecast, and the
  cutover with preconnect. This needs a two-cluster bed.
- **Reading a plan back after it was deleted**, where `GET` answers 404. The
  path is a single `failOps`, and no test covers it.
